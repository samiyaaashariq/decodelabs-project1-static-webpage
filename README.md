DecodeLabs Project 1 – Static Webpage Design

Overview

This project was developed as part of the DecodeLabs Frontend Development Internship Program.

The objective of this project is to create a clean, responsive, and visually appealing static webpage using HTML and CSS while following proper semantic structure and styling practices.

Features

* Semantic HTML structure
* Responsive layout
* Modern UI design
* Navigation bar
* About section
* Services section
* Learning in Action section
* Contact section
* Custom CSS styling

Technologies Used

* HTML5
* CSS3

Learning Outcomes

Through this project, I gained hands-on experience in webpage structuring, CSS styling, responsive design, and frontend development best practices.
